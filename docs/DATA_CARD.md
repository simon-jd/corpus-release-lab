# Dataset card: Corpus Release Lab qualification inputs

## Purpose and use

These inputs qualify a local training-data publication contract. They are not a model-training corpus and do not establish downstream model quality. The release pipeline accepts caller-owned or explicitly licensed UTF-8 JSONL text, outputs Parquet shards, and preserves source bytes and row-level decisions.

## Sources and permission

1. **Scale fixture, unique-sha256-words-v1**: generated by this project, designated CC0-1.0. Each row contains 64 deterministic SHA-256 words derived from its row index. The frozen input contains 255,318 rows and 1,073,743,632 bytes; SHA-256 is `36057ff6d3e0d30f8283516f562bcafd75ad84bef5960b6b4716b204047ba026`. No external personal text or web crawl is included. It has little linguistic diversity and high uniqueness; throughput and compression cannot be extrapolated to natural text.
2. **Rule fixtures**: project-authored synthetic JSONL with empty/short text, invalid encoding, malformed JSON, replacement characters, normalized whitespace, duplicates and repeated content across train/test. Source bytes remain available even when decoding fails. Test code states expected results directly.
3. **PAWS-Wiki evaluation sample**: 200 validation and 200 test pairs from Google LLC's published human-labeled PAWS-Wiki Labeled (Final) dataset. This is an isolated lexical near-duplicate stress test, not an input to a training release. The project reuses published human judgments; it does not claim to have recruited annotators or independently human-reviewed them. The dataset's supplied permission text is retained in `fixtures/near-duplicates/PAWS-LICENSE.txt`; source citations and pinned mirror revision/hashes are in the sample JSON.
4. **LakeBridge integration fixture**: project-owned synthetic tenant/event records generated by LakeBridge. The adapter reads an explicitly published Iceberg snapshot, excludes tombstones with a recorded predicate, and projects selected fields into JSON text. This is a controlled source-integration demonstration, not customer data or a natural-language training-quality claim.

## Transformation and splits

Unicode NFKC and whitespace collapse precede case-sensitive exact hashing. Empty, short (<20 characters), malformed and invalid-encoding records reject. Test takes precedence over validation, then train for exact duplicate groups; original line order breaks ties. Shards sort by normalized hash. Explicit input splits are used; seed is recorded but does not create randomized splits in v1. Every input line appears once in the audit, including normalized-content hash and a decision. Raw bytes are kept unchanged.

Tokenization is disabled (`tokenizer: null`). Near-duplicate filtering is disabled: lexical candidates require review. No semantic leakage-free or model-training exactly-once claim is made.

## Identity, provenance and lifecycle

Dataset identity hashes the source, fixed rules/configuration, dependency versions and artifact hashes. Optional upstream provenance becomes part of identity; LakeBridge receipts bind the release record, snapshot pointer, projection, source hash and upstream code hashes. A caller supplies source rights; a license string or hash is not independent verification of legal rights or provenance authenticity.

A release remains retained until explicit expiration. Consumers pin versions before use. CURRENT and pinned releases cannot expire. A durable tombstone immediately prevents new reads and retries can finish interrupted deletion. An explicit processing revision distinguishes intentional reprocessing of an expired input. Source copies intentionally increase retained storage.

## Quality and representativeness

The scale fixture has 100% accepted unique rows by construction; that is not measured real-world filtering quality. PAWS pairs deliberately emphasize high lexical overlap with sometimes different meanings. Precision/recall against these human semantic labels characterize that adversarial sample, not the precision/recall of duplicate removal in an arbitrary corpus. Full threshold curves, confusion counts and false-deletion examples are retained; no quality benefit is inferred from fewer output files.

## Reproduction and evidence

- `scripts/benchmark.py`: creates or verifies the scale source and measures a publication subprocess.
- `scripts/evaluate_near_duplicates.py --from-fixture`: reproduces the offline quality report without a network request.
- `scripts/qualify_lakebridge_upstream.py`: runs real Spark/Iceberg source qualification in LakeBridge's pinned environment.
- `corpus_release.reconcile.reconcile`: checks sample/audit/source consistency and exact cross-split leakage in addition to artifact hashes.
- `evidence/scale-*.json`, `evidence/near-duplicates.json`, `evidence/qualified-tests.xml` and the LakeBridge integration bundle retain observed outcomes. Earlier failures remain separate historical evidence.
